# Kavinaya P — Portfolio

A custom, responsive developer portfolio built with HTML, CSS and vanilla JavaScript. It uses a cinematic dark base with pink, blue, red, brown, purple and white accents, custom CSS illustrations, animated orbit systems, scroll reveals, tilt cards, responsive navigation and a video backdrop.

## Run locally
1. Extract this folder.
2. Open it in VS Code.
3. Run `index.html` using the Live Server extension, or open it in a browser.
4. Internet access is used for Google Fonts, Font Awesome CDN and the remote hero background video.

## Included
- `index.html` — 20 numbered portfolio sections and profile links
- `style.css` — responsive theme, 3D effects, animations, media queries
- `script.js` — reveal observer, progress bar, cursor glow, mobile menu, tilt and reduced-motion handling
- `assets/` — portrait, certificate images and certificate PDFs
- `Kavinaya_P_Resume.pdf` — resume download

## Notes
- Portfolio content reflects details in the supplied resume and available certificates. The project Vaqelune/MealMate is labeled in progress.
- The GitHub profile, LinkedIn profile, LeetCode, HackerRank and email links use details in the resume / user context.
- The AI for Bharat project is described as a hackathon prototype; no unsupported repository URL is invented.
- Some decorative visuals are custom CSS illustrations rather than external stock images.
- The remote video requires internet access. The site remains usable if the video cannot load.
- Reduced-motion preferences are respected.
